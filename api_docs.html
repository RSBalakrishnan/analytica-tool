1. Website SDK Integration

INTEGRATION

Embed the Tracking Script

Paste this script tag into the <head> of every page you want to track.

How it works: The script automatically detects the tid from incoming links, manages the user session, and sends engagement pulses to your analytics server. 
<script 
  src="http://3.110.134.234:3000/sdk/analytica.js" 
  data-endpoint="http://3.110.134.234:3000"
></script>

Note: Ensure the data-endpoint matches your production server URL.

2. Identity Management

POST
http://3.110.134.234:3000/track/id

Generate a unique Tracking ID with fully qualified URLs.

Use Case: Call this when preparing an email campaign. Use the returned pixelUrl and redirectUrlBase to prepare your trackable messages.

Request Payload

{
  "targets": [
    "https://mysite.com/pricing",
    "https://mysite.com/docs"
  ]
}

Response Structure

{
  "trackingId": "Vx74ALvyQxr3NUhDyJBR4",
  "pixelUrl": "http://3.110.134.234:3000/pixel/Vx74ALvyQxr3NUhDyJBR4",
  "redirectUrlBase": "http://3.110.134.234:3000/r/Vx74ALvyQxr3NUhDyJBR4?url=",
  "links": [
    {
      "original": "https://mysite.com/pricing",
      "tracking": "http://3.110.134.234:3000/r/Vx74...urling"
    }
  ]
}

3. High-Precision Tracking

GET
http://3.110.134.234:3000/pixel/:trackingId

The invisible 1×1 GIF open tracker.

Use Case: Embed this in the HTML <img> tag of an email. When the user opens the email, the transparent pixel is requested, logging the open instantly.

Response

Returns binary image data (image/gif). No JSON body.

GET
http://3.110.134.234:3000/r/:trackingId?url=TARGET_URL

Link click interceptor and tracking propagator.

Use Case: Use this URL for all links in your emails. When clicked, it logs the LINK_CLICK event and redirects the user to their destination while injecting the tid for browser tracking.
POST
http://3.110.134.234:3000/events

Batch ingestion for browser-side behavioral tracking.

Use Case: Integrated into the JavaScript SDK. It sends PAGE_VIEW, PULSE, and EXIT events automatically as the user interacts with your site.

Request Payload

{
  "trackingId": "Vx74ALvyQxr3NUhDyJBR4",
  "sessionId": "sess_r9ktdew11",
  "events": [
    { 
      "eventType": "PAGE_VIEW", 
      "timestamp": 1776422480506, 
      "metadata": { "url": "/docs" } 
    }
  ]
}

4. Smart Analytics & Journeys

GET
http://3.110.134.234:3000/analytics/tracking/:trackingId

Get the complete sequence of user engagement.

Use Case: Use this to display a "Customer Path" or "Journey Map" in your dashboard. It automatically segments the raw data into a readable chronological timeline.

Response Example

{
  "summary": {
    "totalTimeSpentSeconds": 142,
    "timeline": [
      { "url": "/home", "enteredAt": 123456, "duration": 30 },
      { "url": "/pricing", "enteredAt": 123486, "duration": 12 }
    ]
  }
}
GET
http://3.110.134.234:3000/analytics/email/:trackingId

Specific check for email interaction status.

Use Case: Perfect for a "Sales List" view where you just need to know if the email was opened and how many times.

Response Structure

{
  "trackingId": "...",
  "isOpened": true,
  "openCount": 3,
  "lastOpened": 1776422215007
}
GET
http://3.110.134.234:3000/analytics/page?url=ANY_PAGE_URL

Aggregate global stats for a specific URL.

Use Case: Identify which pages are the most popular and have the highest "attention retention" across all users.
GET
http://3.110.134.234:3000/analytics/page/details?url=ANY_PAGE_URL

Granular visitor-level data for a specific URL.

Use Case: Deep-dive into a specific page to see exactly which Tracking IDs visited it and what actions they took on that page.

Response Example

{
  "url": "/pricing",
  "totalUniqueVisitors": 2,
  "visitors": [
    {
      "trackingId": "Vx74AL...",
      "events": [
        { "eventType": "PAGE_VIEW", "timestamp": 123456 },
        { "eventType": "LINK_CLICK", "timestamp": 123478 }
      ]
    }
  ]
}
